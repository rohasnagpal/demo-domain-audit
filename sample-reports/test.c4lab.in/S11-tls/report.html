Glossary

Terms used in this report

TLS
Transport Layer Security, the protocol that encrypts HTTPS. Versions 1.2 and 1.3 are current; 1.0 and 1.1 are deprecated (RFC 8996).
Cipher suite
The combination of key exchange, authentication, bulk encryption and integrity algorithms negotiated for a connection, for example TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256.
AEAD
Authenticated Encryption with Associated Data (AES-GCM, ChaCha20-Poly1305): modern modes that encrypt and authenticate in one step.
CBC
Cipher Block Chaining: an older mode that relies on a separate MAC and has a long history of padding-oracle and timing attacks.
Forward secrecy
Ephemeral (EC)DHE key exchange ensures that a stolen server private key cannot decrypt previously recorded traffic.
SAN
Subject Alternative Name: the list of hostnames and IP addresses a certificate is valid for.
Chain of trust
The path from the server's certificate through intermediate certificates to a root certificate trusted by the client.
